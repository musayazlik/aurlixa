# Better Auth + Prisma + PostgreSQL + Plunk + React Email

## Hedef
Mevcut localStorage tabanlı mock auth (`auth-provider.tsx`) tamamen kaldırılıp gerçek bir auth altyapısına çevrilecek: Better Auth (email+password, e-posta doğrulama zorunlu), Prisma + PostgreSQL kalıcılığı, Plunk ile mail gönderimi, React Email ile marka uyumlu şablonlar. Mevcut `useAuth()` API yüzeyi korunacak; header, hesap, checkout gibi tüketiciler bozulmadan çalışacak.

## 1. Paketler
- `better-auth`, `@prisma/client` + dev: `prisma`, `@react-email/components`, `react-email` (önizleme CLI'sı)

## 2. Ortam değişkenleri
- `.env` + `.env.example`: `DATABASE_URL` (local Postgres, `aurlixa` db'si oluşturulur), `BETTER_AUTH_SECRET` (üretilir), `BETTER_AUTH_URL=http://localhost:3000`, `PLUNK_SECRET_KEY` (siz ekleyeceksiniz; boşsa dev fallback devrede)
- `.gitignore`'un `.env`'i kapsadığı kontrol edilir

## 3. Prisma
- `prisma/schema.prisma` (postgresql) + `src/lib/prisma.ts` singleton
- Better Auth şeması `@better-auth/cli generate` ile üretilir (User, Session, Account, Verification)
- `package.json` script'leri: `db:generate`, `db:push`; `prisma db push` çalıştırılır

## 4. Better Auth server — `src/lib/auth.ts`
- `prismaAdapter(prisma, { provider: "postgresql" })`
- `emailAndPassword`: enabled, `requireEmailVerification: true`, `minPasswordLength: 6` (mevcut UI metniyle uyumlu), `sendResetPassword` → şifre sıfırlama şablonu
- `emailVerification`: `sendVerificationEmail` → doğrulama şablonu, `sendOnSignUp: true`, `sendOnSignIn: true`, `autoSignInAfterVerification: true`
- Route handler: `src/app/api/auth/[...all]/route.ts` (`toNextJsHandler`)

## 5. Mail katmanı
- `src/lib/email/plunk.ts`: `sendEmail({ to, subject, html })` — `POST https://next-api.useplunk.com/v1/send` (Bearer sk_...). Anahtar yoksa HTML sunucu konsoluna yazılır (anahtar eklenene kadar test edilebilirlik için)
- `emails/verify-email.tsx`, `emails/reset-password.tsx` — marka renkleriyle (ivory/espresso/gold), `PreviewProps` ile react-email önizlemesinde görülebilir; `"email:preview"` script'i (`email dev --port 5555`)

## 6. Client tarafı
- `src/lib/auth-client.ts`: `createAuthClient()` (better-auth/react)
- `auth-provider.tsx` yeniden yazılır: aynı API (`user {name,email,since}|null|undefined`, `login/register/logout` — artık async, `since` = `createdAt`), `useSession` tabanlı; eski `aurlixa-user`/`aurlixa-users` localStorage anahtarları tek seferde temizlenir
- `login-form`: async login; doğrulanmamış e-posta hatasında "doğrulama maili gönderildi" bilgilendirmesi
- `register-form`: kayıt sonrası `/hesap` yerine "e-postanı doğrula" ekranı
- `forgot-form`: `authClient.forgetPassword` (redirect: `/sifre-sifirla`)
- Yeni sayfalar: `/sifre-sifirla` (token + yeni şifre → `resetPassword`), `/dogrulandi` (doğrulama callback'i; otomatik giriş sonrası `/hesap`'a yönlendirir)

## 7. Doğrulama
- `prisma db push` → dev server'da uçtan uca akış testi (kayıt → mail/link → doğrulama → otomatik giriş → /hesap; şifre sıfırlama; header/checkout entegrasyonu), `tsc --noEmit` + playwright ile sayfa kontrolleri
- Not: `tsc`'de halihazırda `cart-provider`/`cart-view`/`checkout-flow`'da benim dokunmadığım önceden var olan tip hataları var; auth kapsamı dışında bırakılacak (sadece auth'ın kirlendiği yerde düzeltilir)

## Kapsam dışı
Sosyal giriş, 2FA, admin paneli, proxy ile route koruması (mevcut client guard kalır), sipariş verisinin DB'ye taşınması.
